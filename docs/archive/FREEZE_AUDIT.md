## 1. 审查结论

1. Q1–Q162 覆盖的业务模块、工作区、归档、检索、导出、数据库加密、回收站和 Windows 便携部署需求，已达到**停止逐题追问并进入设计阶段**的程度。此前的问答中存在多轮明确撤销，必须以后面的修订为准，不能取最早答案。
2. 已识别的**真实数据安全冲突**是 Q4「可选导入后删除源文件」与 Q101「仅在安全退出后手工复制数据库备份」：若只有导入前旧备份，不能证明本次新文件得到备份。冻结基线保留原始数据安全前提：**未能验证包含本次入库数据的有效备份时禁止程序自动删除源文件**，不靠猜测或用户勾选豁免。
3. 在 2026-10-13 的初次审查时，`DESIGN.md` 仍含跨平台、多公司、提醒、清单、扩展字段与自动备份等已撤销概念；**截至 2026-10-15，该文件已改为当前代码的技术说明**，但 M2 技术评审、数据安全与兼容专项验收仍未全部完成。
4. Q163 是尚未回答的问题，**不能伪称已经得到用户选择**。依据 Q40 固定列 XLSX 与 Q95「隐藏列只影响界面」既有要求，V1.0 暂按模块固定字段导出台账，不增加字段选择功能。字段清单及列顺序将在字段字典阶段形成，可按变更流程复核。
5. 已冻结的是“做什么”，不是“每一个技术参数”。停止无限延伸的 A/B/C 提问，将技术实现问题交给方案、实验和验收测试。

## 4. 明确不纳入 V1.0 的功能

不包含多用户/账号权限、云同步、macOS/Linux 可执行版本、多公司主体、公司与个人共享相同物理附件、可自定义数据库字段、审批流、专利年费/证书/合同到期提醒、材料收集清单、文件待整理区、无归属文件的通用文件池、自动保留上传原始磁盘目录结构、PDF/Office 正文 OCR 与全文搜索、复杂自然语言检索、自动备份或备份向导、密码找回、操作审计记录、自动锁屏、跨模块文件篮、SQL/SQLite 对外导出、台账与全部附件一键打包、断点续传或并行大文件任务。

这部分以 `REQUIREMENTS.md` 中明确覆盖条款为准；`DESIGN.md` 中出现同名功能**不构成恢复功能的依据**。

## 5. 开发前必须验证的技术门槛（不再逐题提问）

| 门槛 | 需要证明的结果 | 未通过时的处理 |
| --- | --- | --- |
| T01 加密存储 | Windows x64 目标运行环境中使用实际 SQLCipher 整库加密，密码错误不能读取、原件不以明文持久落盘；当前单 EXE 依赖外置 .NET 8 两类运行时 | 验证未通过前不交付长期保存唯一原件的正式版本 |
| T02 大文件 | 超过 2 GB 的附件在目标 5–20 GB 数据库内分块导入、读取、校验和导出，原件哈希一致，内存不随文件大小线性增长 | 调整实现后复测，不改“原件必须入库”产品要求 |
| T03 移动 SSD 与异常 | 突然拔出、写入失败、容量不足、取消导入后，数据库与附件引用可验证，不把半成品视为成功 | 暂停相关写入功能发布 |
| T04 备份一致性 | 安全退出后确认数据库及 WAL/日志状态已正确收尾；从 Windows Explorer 复制的完整数据库在另一位置可独立解密并完成一致性检查 | 不宣称复制单个文件一定是有效备份 |
| T05 目录保存 | 在 Edge/Chrome 浏览器与 localhost 本地宿主场景中，用户每次可选目标路径并导出完整目录/ZIP；不得依赖浏览器未授权的任意磁盘写权限 | 原型验证选择器与本地服务的数据传输方式 |
| T06 工作区隔离 | 公司与个人在同库中隔离记录与附件二进制，同区共享附件且跨区复制有独立字节；搜索、导出和预览不能泄露另一工作区数据 | 阻止上线并整改数据访问边界 |
| T07 浏览器退出 | 安全退出的三选项及最后应用页面关闭时的尽力原生提示不丢已提交数据；浏览器无法提示时本地服务能安全取消 | 修正后台生命周期控制，不声称浏览器确认可靠必现 |
| T08 V2 版本与未来升级 | V2 版本可识别；旧测试库明确拒绝且不覆盖原文件，未来 V2 受控升级须验证完整性和备份，不承诺旧程序读取 V2 | 新库版本拒绝/文件保护的真实 Windows 测试；未来升级按实际需求另定安全验收 |
| T09 源文件删除安全 | 如实现 Q4 的有条件删除，必须能证明源文件字节已完整入库并已经存在包含该版本的新有效外部备份，且不违背手工备份规则 | **条件未满足则保持原件不删除**，不得推出“入库成功立即删源” |

### 关键验收样例

1. 同一专利上传一份文件 V1/V2/V3：正常勾选只导出 V3；V1 可在历史页单独导出；原文件名及哈希符合规则。
2. 两个项目引用同一个原件且均勾选导出：数据库只需一份共享二进制，但两个项目文件夹必须各有完整文件。
3. 项目合同附件导出为「项目名/合同名/原文件名」，不自动包含未选择的合同附件。
4. 批量导入途中磁盘写满：此前成功文件正常，当前未完成附件不可见，下一次打开数据库仍可校验。
5. 对 ZIP 导出取消：不保留未完成 ZIP；正常结束仅部分附件失败：生成可正常打开的 ZIP 并列出失败清单。
6. 导出 Excel「筛选结果」可覆盖所有匹配记录而不限当前滚动已加载的部分，「全部记录」不带跨工作区内容。
7. 在安全退出后手动复制库，并从副本打开校验，再考虑任何外部源文件删除；无有效新备份不得由软件删除。
8. Edge 与 Chrome 中完成重复导出目录自动加后缀，并在两者上均可人工选择本次输出位置。
