## 7. 最该先修的 5 件事（按根因归并，不是按用例数）

1. **`store.js` 的 buildArchiveDirs 只取顶层目录**（`492-493`）—— 一处改动同时解决 BUG-001 与 BUG-010 的"目录节点丢失"半边。
2. **附件行的唯一性口径**：接口按版本出行 + 前端用 `f:linkId:version` 作 id，两处叠加导致 BUG-002；而 BUG-003、R-05 的翻倍都是它的下游。**先定"一 link 一行、版本走历史"这条口径，再改两端。**
3. **`deleteNodes` 的批处理容错**（BUG-003）：逐条 try、收集成功/失败明细、结束必 `refreshCurrent()`。
4. **PDF 预览缺一句 `viewer.create(...).open()`**（BUG-018）—— 一行改动，但影响整个预览能力。
5. **`loadAll` 的 `.catch(() => [])`**（BUG-019）：至少把失败模块记进 `VaultStore.error` 并在界面上给一行可重试提示。
