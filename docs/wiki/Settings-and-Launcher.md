# 设置与 Windows 启动器

## WinForms 与本机浏览器

双击 `IPSys.Web.exe` 会启动 Windows 窗口及本机 Web 服务。点击“打开管理界面”后，由 Edge/Chrome 打开本机页面；网页不是独立云服务。

启动器中的关闭按钮 × 默认**隐藏到系统托盘**，而非退出程序。双击托盘图标可恢复窗口，右键菜单可打开主窗口或安全退出。网页上的“关闭数据库”只是锁定并结束当前资料会话。

## 数据库路径

登录页会建议 EXE 同目录的资料库路径，也可以使用文件夹图标选择已有库或新库保存位置。当前新建库使用 SQLCipher schema 4，旧 schema 2/3 不自动迁移；切勿因旧库无法兼容而直接覆盖原 DB。建议将 EXE 与正式 DB 的备份分别维护，避免升级 EXE 时误操作数据库。

## 资源与容量

启动器可显示本程序及整台电脑的 CPU 占用，用于粗略观察运行负载；其中本程序数值不包含所有外部浏览器进程。

首页或侧栏数据库容量表示 SQLCipher 文件内部页面统计：总页面大小、已用页面和空闲页，并非电脑硬盘剩余空间。永久删除可能使空闲页增加，但实际 DB 文件长度不立刻下降。

## 软件更新

已解锁资料库时，可在「设置 → 软件更新」查看 EXE 实际版本并手动点击「检查更新」。打开资料库后还会尝试一次后台检查；成功结果及同版本提醒约 24 小时限频，断网时不影响离线使用。检测到 GitHub 官方较高版本后只出现非模态提醒，点击后打开对应 Release 下载页面；是否下载、替换 EXE 由用户决定，不执行自动安装，也不修改本地 SQLCipher 数据库。开发构建没有正式发行版本号时不做错误的新旧版本比较。

## 修改资料库密码

进入「设置 → 数据库 → 修改密码」，需要当前密码与两次相同的新密码（8–256 字符）。这是真正的 SQLCipher 数据库密钥轮换，个人和企业工作区共用；会重写所有加密数据页，对大库可能耗时较长。务必先安全关库并备份加密数据库文件。执行期间不能进行上传、永久删除、压缩或强制退出；成功后自动关库并失效化旧浏览器令牌和 MCP 授权，使用新密码重新打开。程序将验证新密码生效、旧密码失效以及数据库完整性；不自动生成备份。

## 完整性检查进度

在「设置 → 数据库 → 完整性检查」启动异步任务后，界面显示真实服务器阶段及不确定进度条。SQLite 的 `PRAGMA integrity_check` 无法可靠给出百分比，不会用虚构的 50%/90% 代替进度；它会在后台检查加密数据页，再统计未完成附件，完成后显示结果。暂时关闭设置不会取消后台检查，重新打开会接续查看。检查占用数据库任务锁，避免与压缩、删除和上传等任务冲突。



设置中有手动压缩数据库功能，适合在已经永久删除较多内容后使用。压缩通过 SQLCipher/SQLite `VACUUM` 创建临时数据库和回滚日志，最坏情况下需要额外约原 DB 文件两倍的空间；本项目再增加 128 MiB 安全余量，并检查数据库盘及系统临时目录。额外空间在操作结束后释放，并非永久占用；不要强制断电或终止进程，也不会自动备份。

## Agent 工作规范与 MCP

设置中可以查看、调整、恢复和备份 Agent 专项工作规范；真正要让本机 Agent 查询或写入资料，仍需核对本机 MCP 授权状态；每次解锁资料库后默认开启，用户可在设置中手动关闭。MCP 仅限当前 Windows 用户的本地授权会话，关闭库或修改密码时立即撤销。参见 [[Agent 工作规范|Agent-Guidance]]。

## 与资料安全有关的操作

在多个大文件上传、永久删除和压缩任务期间退出时，应按照软件的取消、任务完成后退出或暂不退出选项处理。建议以最终确认结果为准，不根据界面进度条独立判断写库完成。
