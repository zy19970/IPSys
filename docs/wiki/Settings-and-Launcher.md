# 设置与 Windows 启动器

## WinForms 与本机浏览器

双击 `IPSys.Web.exe` 会启动 Windows 窗口及本机 Web 服务。点击“打开管理界面”后，由 Edge/Chrome 打开本机页面；网页不是独立云服务。

启动器中的关闭按钮 × 默认**隐藏到系统托盘**，而非退出程序。双击托盘图标可恢复窗口，右键菜单可打开主窗口或安全退出。网页上的“关闭数据库”只是锁定并结束当前资料会话。

## 数据库路径

登录页会建议 EXE 同目录的资料库路径，也可以使用文件夹图标选择已有库或新库保存位置。建议将 EXE 与正式 DB 的备份分别维护，避免升级 EXE 时误操作数据库。

## 资源与容量

启动器可显示本程序及整台电脑的 CPU 占用，用于粗略观察运行负载；其中本程序数值不包含所有外部浏览器进程。

首页或侧栏数据库容量表示 SQLCipher 文件内部页面统计：总页面大小、已用页面和空闲页，并非电脑硬盘剩余空间。永久删除可能使空闲页增加，但实际 DB 文件长度不立刻下降。

## 数据库压缩

设置中有手动压缩数据库功能，适合在已经永久删除较多内容后使用。压缩会涉及数据库重写与完整性检查，须有足够可用空间，完成前不要强制断电或终止进程。

## Agent 工作规范与 MCP

设置中可以查看、调整、恢复和备份 Agent 专项工作规范；真正要让本机 Agent 查询或写入资料，还需要单独开启 MCP 授权。参见 [[Agent 工作规范|Agent-Guidance]]。

## 与资料安全有关的操作

在多个大文件上传、永久删除和压缩任务期间退出时，应按照软件的取消、任务完成后退出或暂不退出选项处理。建议以最终确认结果为准，不根据界面进度条独立判断写库完成。
