# 工作区与业务模块

同一个 SQLCipher 加密库内有**个人工作区**和**公司工作区**。两者共享同一数据库文件，但业务归属、查询和附件权限分别处理。默认进入个人工作区。

## 公司工作区

| 模块 | 典型内容与管理方式 |
| --- | --- |
| 企业资质 | 资质证书、证照、相关材料台账 |
| 业务档案 | 以文件夹为入口的业务资料归档；新库初始化七个普通一级目录 |
| 公司项目 | 科研、横向及其他项目；合同扫描件和相关材料存放在项目的普通子目录中 |
| 知识产权 | 专利、著作权、商标、标准等十类业务记录 |
| 综合资料 | 通用资料与附件归档 |
| 党团建设 | 独立的党团资料模块 |

## 个人工作区

| 模块 | 典型内容与管理方式 |
| --- | --- |
| 人力资源 | 个人身份及证书材料 |
| 知识产权与著作 | 个人知识产权与作品记录 |
| 科研与合作项目 | 个人项目、合作与相关材料 |
| 成果与奖励 | 论文、获奖、成果证明等资料 |
| 学术与社会活动 | 学术兼职及社会活动材料 |
| 其他资料 | 个人通用归档 |

## 多级目录支持范围

公司“企业资质、业务档案、综合资料、党团建设”四个模块，以及个人“人力资源、成果与奖励、学术与社会活动、其他资料”四个模块，采用统一的普通文件夹：可以在目录中直接上传附件，也可以继续建下级目录，名称必填，其他属性选填。

公司项目、知识产权，以及个人知识产权和科研项目，保留各自的专用业务属性和表单；附件仍使用统一的版本与共享原件机制。

## 公司业务档案初始七目录

新建资料库时默认创建：申报与认定、规划与管理、汇报与宣传、会议与活动、专项工作与合作、政策与行业资料、其他业务资料。

它们**创建以后就是普通文件夹**，可以按权限进行改名、移动、排序和回收；并非不可变更的系统保护目录。若用户删除或改名，软件不应再次强制创建原目录。

## 合同为什么不单独成模块

系统没有独立合同业务记录、合同专用表单或合同 Excel 台账。需要归档合同时，在实际项目下新建普通文件夹，可按需要嵌套并直接存放扫描件、协议、补充材料等附件；这些目录遵循普通文件夹的移动、共享、删除与恢复规则。
