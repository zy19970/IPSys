# 知识产权台账

IPSys 将专利、著作权、商标、集成电路布图设计和标准统一到知识产权模块管理，但各类型仍保留适用的特定字段。

## 十种业务类型

1. 发明专利
2. 实用新型专利
3. 外观设计专利
4. 软件著作权
5. 其他著作权
6. 商标
7. 集成电路布图设计
8. 国家标准
9. 行业标准
10. 企业标准

知识产权列表顶部的“筛选”针对上述业务类型，而不是将“已授权、已登记、已发布”等状态当作类型。

## 三个编号框

| 字段 | 如何填写 |
| --- | --- |
| 统一编号（`number`） | 专利申请号、著作权登记号、商标申请/注册号、标准号等 |
| 公开号（`publication_no`） | 适用的专利有公开信息时填写 |
| 授权公告号（`grant_notice_no`） | 适用的专利已有授权公告时填写 |

这三个编号均是可选项，**名称和知识产权类型是基本必填项**。软件著作权、标准等通常只需要第一个统一编号；不应为没有公开号的记录编造后两个编号。

## 日期、状态和年份

知识产权的“年份”只取**申请日期的年份**。例如申请日为 2023 年、授权日为 2026 年，列表年份仍是 2023；如果申请日为空，即使存在授权或登记日，也不应自动填其他年份。

状态用于表示流程或有效性阶段；它和知识产权业务类型是两个不同维度。不同类型会有适用的日期、权利人及公告信息字段；对于没有实际意义的字段可以留空。

## Excel 与附件

知识产权使用当前版本提供的固定 XLSX 模板，当前源码采用 19 字段口径。Excel 可按类型筛选导出或导出本模块全部适用记录，不包括 PDF 等原件。专利证书、受理通知书、软著登记证书等应作为附件另行上传。

同一知识产权业务记录可以有多个附件，附件各自管理版本。详细规则参见 [[搜索与 Excel|Search-and-Excel]]、[[文件共享与版本|File-Sharing-and-Versions]]。
