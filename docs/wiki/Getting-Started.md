# 快速开始

## 运行环境

IPSys 面向 Windows x64，使用本地 WinForms 窗口和 Edge/Chrome 浏览器。程序不需要自行部署网站或购买服务器；网页地址只绑定到本机回环接口。

从 [GitHub Releases](https://github.com/zy19970/IPSys/releases) 选择需要的已发布版本，或从 [Actions](https://github.com/zy19970/IPSys/actions) 获取与特定源码提交对应的构建工件。下载前确认版本、构建结果及是否为预发布，并区分：

| 构建方式 | 使用条件 |
| --- | --- |
| 自包含版（SelfContained） | 已打包所需 .NET 运行组件，普通使用优先选此版 |
| 依赖运行时版（framework-dependent） | 目标 Windows 需要相应的 .NET 8 Desktop Runtime 和 ASP.NET Core Runtime（x64） |

下载 Actions 工件时通常先得到 ZIP，需要解压并运行其中的 EXE。Windows 如弹出未知发布者提示，应先确认来源、发布记录及文件完整性，再决定是否运行。

## 第一次创建资料库

1. 将 EXE 放在具有写入权限的位置，例如 `D:\资料管理系统\`。
2. 双击运行程序，在启动器中选择打开管理界面；浏览器显示本机登录页。
3. 点击“创建新资料库”，通过文件夹按钮选择新数据库路径。
4. 设置并确认密码，完成创建后进入资料工作台。
5. 默认进入个人工作区，可按需要切换到公司工作区。

通常可以把 EXE 与数据库放在同一文件夹，但**数据库路径不强制跟随 EXE**。已有数据库从登录页选择文件、输入原密码打开，不需要重新创建。

## 老用户打开已有资料库

现行程序新建 SQLCipher schema 4 资料库；旧 schema 2/3 测试库不自动迁移。遇到旧库版本不兼容时先保留原件，不要通过新建流程覆盖旧文件。


1. 启动 EXE 并打开管理界面。
2. 在登录页选择既有 `.db`、`.sqlite` 或 `.sqlite3` 文件。
3. 输入数据库密码进入工作台。

登录页会优先建议 EXE 同目录的资料库位置，但不自动搬移或覆盖文件。只有数据库文件与正确密码才能重新打开已有资料。

## 首次归档示例

1. 选择“公司”工作区并进入“业务档案”。
2. 打开适合的一级目录，例如“申报与认定”。
3. 点击“新建”直接创建下级文件夹，名称必填、其余属性选填。
4. 在该文件夹中直接上传一个或多个附件，可同时继续添加下级文件夹。
5. 返回列表，检查资料名称、附件数量与实际归属。

## 退出与备份

网页中的“关闭数据库”是锁库并返回登录页面。启动器右上角的 × 通常隐藏到系统托盘；真正退出请点击“退出程序”，并处理仍在进行的文件任务。

第一次创建资料后建议立即阅读 [[备份与数据安全|Backup-and-Security]]。
