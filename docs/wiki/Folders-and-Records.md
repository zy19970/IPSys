# 目录与资料记录

IPSys 将分类目录、项目、合同、知识产权记录等业务对象统一组织为 Folder；真实附件是 File。**Folder 不具有附件版本，只有 File 可以有历史版本。**

## 两种看起来像文件夹的对象

**普通目录**负责归类、导航和层级整理，目录下面可以继续建立普通目录，也可以放业务资料记录。

**资料记录**负责保存一条业务数据，例如名称、类别、年份、备注及附件。点击记录进入后可以查看或上传原件。

这两个对象在界面上可能都能打开，但不要把“再建一级普通目录”和“给资料记录上传附件”混为一谈。

## 七模块递归目录

在 [[工作区与业务模块|Workspaces-and-Modules]] 所列的七个资料模块中，支持：

1. 在模块根层创建目录或记录，并根据业务页面规则呈现。
2. 在任意普通目录继续新建下级目录或资料记录。
3. 对同层普通目录和资料记录统一排序，不强制目录永远排在记录上方。
4. 移动、重命名和批量导出适用的目录或资料。
5. 将整个普通目录连同其后代移入回收站，再按根目录恢复。

目录存在层级和循环引用校验，不能移动到自身或其子孙目录之下，也不允许跨工作区错挂父级。

## 建议的资料组织方法

例如公司业务档案可整理为：

~~~text
业务档案
  申报与认定
    2026年度
      申报材料（资料记录）
        申请书.pdf
        附件清单.xlsx
      过程文件（普通目录）
        会议材料（资料记录）
~~~

其中“申报材料”是记录，“申请书.pdf”才是该记录中的附件。附件如果需要在其他位置重复出现，可通过明确的共享或复用操作建立关联。

## 删除与恢复目录

普通删除目录是软删除，目录根进入回收站，其全部下级目录、记录和附件保持可恢复关系。永久删除时才递归解除关联并清理不再被引用的原件。参见 [[回收站与彻底删除|Recycle-Bin]]。
