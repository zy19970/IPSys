# 搜索与 Excel 台账

## 跨模块搜索

搜索在**当前工作区**内查询项目、知识产权、普通目录（包括项目内合同资料文件夹）、附件名称及明确保存的可检索属性。切换工作区后应丢弃旧工作区搜索结果，避免显示内容混淆。

搜索属于关键词匹配，并非对 PDF、Word 或图片正文进行自动全文 OCR，也不是向量语义搜索。交互式结果可能有分页或每组展示限制。

## 模块筛选

知识产权台账按**业务类型**筛选，如发明专利、软件著作权、国家标准等；“全部类型”清除筛选。其他有状态字段的台账可按业务状态筛选。

筛选 Excel 导出以服务端实际匹配记录为准，不应直接理解为“只导出当前屏幕已渲染的几行”。

## Excel 导入

Excel 是**业务元数据**的台账导入，不会因为在表格中填了名称就自动把 Word、PDF 原件上传到数据库。建议从软件导出当前版本模板，再填写并回导。

支持适用模块的项目、知识产权、资质、业务档案、综合资料、党团建设和个人资料；合同资料作为项目下普通文件夹及附件归档，没有独立合同业务台账或专用 Excel 接口。

导入时可选择跳过重复、更新已有或另外创建，具体匹配规则依模块而异。例如项目优先按项目编号、知识产权优先按统一编号与业务类型匹配。

**更新已有记录时，空白单元格表示保留原值，非空才覆盖。** 如需把原有属性明确清空，应使用软件的属性编辑功能。Excel 更新不得覆盖附件 FileId、文件历史与原件。

## Excel 导出

适用模块可选择“当前筛选结果”或“当前模块全部记录”；两者都只针对当前工作区的适用范围。XLSX 不附带原件，若要拿到文件应使用附件下载或打包 ZIP。

当前固定模板为项目 **11 列**、知识产权 **19 列**、企业资质/业务档案/党团/综合资料等普通目录 **6 列**（资料名称、类别、备注、标签、年度、所属目录）。类别字段不是物理目录路径；合同资料没有独立业务 Excel。**字段与列顺序以当前运行的 EXE 导出模板为准**，不要直接沿用早期的旧表格示例。

## 使用建议

1. 先通过少量样本导出当前模板，核对名称、编号和类型。
2. 批量更新前备份数据库，在几条测试记录上确认匹配规则。
3. 对有附件的真实记录，核查 Excel 更新前后原件与版本是否仍完整。
4. 导出前检查筛选类型，避免把筛选结果误认为模块全量资料。
