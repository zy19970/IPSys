# 搜索与 Excel 台账

## 跨模块搜索

搜索在**当前工作区**内查询项目、知识产权、普通目录（包括项目内合同资料文件夹）、附件名称及明确保存的可检索属性。切换工作区后应丢弃旧工作区搜索结果，避免显示内容混淆。

搜索属于关键词匹配，并非对 PDF、Word 或图片正文进行自动全文 OCR，也不是向量语义搜索。交互式结果可能有分页或每组展示限制。

## 模块筛选

知识产权台账按**业务类型**筛选，如发明专利、软件著作权、国家标准等；“全部类型”清除筛选。其他有状态字段的台账可按业务状态筛选。

筛选 Excel 导出以服务端实际匹配记录为准，不应直接理解为“只导出当前屏幕已渲染的几行”。

## Excel 导出

台账界面仅提供「导出 Excel」，已取消从 Excel 批量导入或回填记录。新增和修改记录请使用对应模块的「新建」或「属性」。已经入库的记录可以继续查看和编辑，Excel 文件可作为普通附件上传。

在适用模块点击「导出 Excel」，选择「导出当前筛选结果」或「导出当前模块全部记录」。两种范围都限定在当前工作区。导出的 XLSX 只包含台账属性，原件请通过附件下载或 ZIP 打包获取。

导出使用固定列：项目 **11 列**、知识产权 **19 列**、适用普通资料 **6 列**（名称、类别、备注、标签、年度、所属目录）。「所属目录」是记录在当前模块内的实际层级。「类别」是独立的业务属性。合同材料在项目内按普通文件夹和附件管理。
