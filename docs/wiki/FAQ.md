# 常见问题

### 这是一款云盘吗？

不是。IPSys 是 Windows 本地加密资料库，界面参考 OneDrive 文件管理方式，但没有因为使用浏览器就自动把文件上传到互联网。

### 把 EXE 删除，资料会跟着丢失吗？

若 DB 文件完整、密码正确且程序版本兼容，删除或更新 EXE 不等于删除 DB 数据。真正需要保护的是 DB 文件、密码与验证过的备份。

### 能把 DB 放在 EXE 旁边吗？

可以。登录页会建议同目录的数据库位置，也允许自己选择其他路径。

### 关闭浏览器等于退出软件吗？

不等于。浏览器只是前端。WinForms 窗口右上角 × 通常隐藏到托盘；要真正退出请明确选择“退出程序”。

### 公司和个人资料用两个 DB 吗？

不是必需。一个加密 DB 内包含分离的两个工作区，但数据访问与物理共享规则不同。

### 所有模块都能无限建立普通目录吗？

不是。公司业务档案、综合资料、党团建设和个人四个资料模块采用多级目录；项目、知识产权等专用模块保持自身的业务结构。

### 文件夹会产生版本吗？

不会。目录和记录是 Folder，文件历史版本属于 File。

### 上传同一个 PDF 两次一定占两份空间吗？

不一定。查重后用户可选择共享 FileId、复用相同物理字节或独立保存。不同选项的版本与共享行为也不同。

### 为什么搜索不到 PDF 正文中的字？

内置搜索主要索引业务属性、附件名称和可选文件元数据，不等于 PDF/Word 正文 OCR 或 AI 语义搜索。

### Excel 导出的文件包含附件吗？

不包含。Excel 是元数据台账；要下载原件请使用附件下载或 ZIP 打包功能。

### 可以在软件里修改加密资料库密码吗？

可以。打开资料库后，在“设置 → 数据库 → 修改密码”输入旧密码与两次相同的新密码（8–256 字符）。这是 SQLCipher 实际重新加密操作，应先安全备份；成功后当前会话失效，需用新密码重新打开。旧密码无法直接找回。

### Markdown 和 TXT 能直接预览吗？

可以。`.md`、`.markdown` 和 `.txt` 支持离线预览，Markdown 可切换排版和源码；文本预览限制在 10 MiB 以内，超过时下载阅读，不影响文件正常存储。

### 如何确认永久删除是否成功？

以服务端任务确认成功为准，不能仅凭进度条 100%。成功面板约四秒后隐藏；错误和取消应保留提示。

### 数据库体积为什么不下降？

永久删除后的空闲页会留在数据库内部供下次写入复用，文件体积不一定下降。想让文件真正变小时，在「设置 → 数据库 → 空闲空间回收」执行；它在原文件内部完成，不需要预留两倍空间，建议先备份。

### 可以让 Codex 自动整理文件吗？

可以通过用户授权的本机 MCP 和 Agent 自身阅读能力完成查询、上传及有依据的属性补录。软件本身不会自动为所有附件理解正文，也不会在用户仅要求清单时自行改写资料。

### Wiki 页面和程序更新会自动同步吗？

不会。Wiki 是文档站点，与 GitHub Release 和用户本机 EXE 分离；程序升级应下载并运行相应发行产物。
