# 备份、数据安全与换电脑

## 什么是真正重要的数据

IPSys 保存内容的核心是**本地 SQLCipher 加密 DB 文件与对应数据库密码**。程序 EXE 可以重装或更新，数据库文件不能靠重装程序自动恢复。

浏览器页面不是云端数据库；本机 `127.0.0.1` 地址只用于本机程序和浏览器交互。IPSys 的 OneDrive 风格指操作体验，不代表拥有 OneDrive 自动云同步能力。

## 正确备份

1. 确认上传、永久删除、空间回收等后台任务已结束并报告成功。
2. 使用启动器或托盘菜单中的“退出程序”安全关闭软件。
3. 把整个 DB 文件复制到其他可靠存储位置，按日期命名备份副本。
4. 在隔离位置用副本验证能打开、能查看关键记录与附件。
5. 妥善保存数据库密码，避免密码与 DB 备份同时无保护暴露。

正在写入时直接拷贝使用中的数据库文件，不能等同于已验证的完整备份。重要资料不要只留下唯一一份数据库文件。

## 换电脑与升级

将可运行的 Windows EXE、备份的 DB 文件和原数据库密码准备好；在新电脑启动程序，选择既有数据库路径并解锁。

**数据库结构是否兼容取决于 EXE 版本。** 当前新建库使用 SQLCipher **schema 4**，旧 schema 2/3 不自动迁移；开发测试阶段不要求自动迁移旧测试 DB。因此更新 EXE 后若旧测试库提示结构约束错误，应先保留原文件并用独立新库验证，而不是直接删除、覆盖或尝试手工修改加密表结构。

未来正式使用时，应把升级兼容策略和备份要求视为发布验收的一部分。

## 密码与访问

可以在已解锁资料库的「设置 → 数据库 → 修改密码」执行 SQLCipher 密钥轮换。应先安全退出、备份加密 DB 并验证备份，再在本机用当前密码和两次相同的新密码操作；成功后旧会话被撤销，须用新密码重新登录。改密不会自动帮用户生成备份。


现有产品不提供忘记数据库密码后直接找回原密码的机制。浏览器关闭数据库会撤销当前会话，但不会退出宿主。MCP 在每次解锁资料库后默认开启，当前 Windows 用户的可信本地 Agent 因此可以执行被授予的读写工具；可以在设置中手动关闭该次资料库会话的 MCP，关闭资料库、改密或退出程序也会撤销授权。本机命名管道不是向互联网开放的公共服务。

## 空闲空间回收

永久删除附件只会解除关联，数据库文件体积不会自动变小；被释放的页面留在库内，下次写入时优先复用，所以日常使用并不会因为“没回收”而膨胀。想把空间真正还给磁盘时，在「设置 → 数据库 → 空闲空间回收」手动执行：它在**原文件内部**分批搬页并截断文件尾，额外占用只有单批回滚日志（约 1 MiB），不需要预留两倍空间，也可以随时取消——取消后已经回收的部分保留。回收前建议先备份，切勿为了释放空间手工删除活动数据库文件。
