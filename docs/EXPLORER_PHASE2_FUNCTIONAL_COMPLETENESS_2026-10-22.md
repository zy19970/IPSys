# IPSys Explorer 第二阶段：功能完整性收敛实施计划

> 适用开发分支：`work/onedrive-file-manager`。本文件为持续执行基线，实际完成状态应以提交、自动回归和最新源码为依据。2026-10-22 用户确认：**先完成第二阶段全部核心功能，再集中由本地 Agent 进行完整稳定性验收**。
>
> 冻结架构：WinForms 启动器 + 本机浏览器前端 + SQLCipher V2 的 Folder/File/Link/Version 资源模型。公司与个人工作区隔离。当前开发数据为测试数据，不安排旧库迁移。

## 一、总体顺序与验收边界

阶段顺序固定为“功能补齐 → 功能整体梳理与互相对照 → 交付本地 Agent 一次性综合验收 → 依据真实证据修复残余问题 → 再讨论并入 main”。

开发期间，每个功能包要求对应源码、最小动态回归、Windows Debug/Release/Node 相关 CI 检查；**不在每个功能包后重复运行本地 Agent 全量黑盒测试**。如果阶段开发中已出现明确的安全或编译阻断，必须先修复，不能带着已知严重风险继续叠加功能。

以前三批缺陷修复为基础，不将测试脚本旧断言误报当成新产品缺陷，也不以单轮 CI 绿灯宣布可正式使用。历史 V2/V3 报告仅属于旧 SHA 的证据。

## 三、实现中的安全和一致性约束

1. **数据模型不变**：Folder 无版本，File 有版本；同工作区共享 FileId 时多个关联可见同一版次，跨工作区必须复制字节。复制、移动和共享必须清楚区分，避免 UI 将“复制记录”误用为“移动文件”。
2. **父子依赖不破坏**：合同只能归属项目；项目整体移动/转移须保持项目与合同、附件关系；业务档案的系统目录不可被非法改名/删除/转移。
3. **不直接把后端拒绝伪装成成功**：409、401、找不到目标及文件任务占用都应该保留会话并显示可理解的错误；无法确定提交成功时不得自动重试非幂等写入。
4. **避免测试污染**：功能回归使用临时资料库及测试数据；改名、移动测试能恢复原状的应恢复。未经另行授权不得用真实业务库做批量删除或跨区转移测试。
5. **持久顺序由服务端决定**：拖动/上移下移等交互必须使用当前父目录完整同级清单提交，禁止把筛选后的子集当作全量覆盖排序；多选/搜索时按规则禁用冲突操作。

## 四、每包完成与阶段结束的判定

每包：代码推送开发分支；新增至少一条真正执行操作路径的回归；必要的 C#/Node 自动门禁通过；记录新增功能对应的入口、接口与测试证据；未通过的步骤必须标为“未完成/失败”。

全部 F2-01～F2-06 完成后，单独核对：无虚假按钮、无遗漏的业务入口、主要模块可新建/编辑/复制/移动/转移/删除/排序、跨工作区与文件共享语义一致、已有缺陷回归均有检查。不在功能尚不齐全时宣布第二阶段结束。

## 五、第二阶段之后：本地 Agent 一次性系统验收

功能开发完成后，生成独立的 **`IPSys_Explorer_Phase2_Agent_Complete_Retest.md`** 与按模块列出的测试用例 CSV，交由用户本地 Agent 在最新开发分支、真实 Windows/Edge 环境和全新隔离 SQLCipher 测试库执行。此文档目前只是规划，未声称 Agent 已经测试。

实机验收至少覆盖：

1. 首次建库、打开现有库、错误密码、会话恢复、重复路径防覆盖以及断开连接后的重新打开。
2. 个人/公司每类业务记录的增删改复制/移动/转移；合同与项目父子关系；公司业务档案的多级目录、混排顺序、系统保护和持久化。
3. 同一 FileId 的不同 LinkId、历史版本同步与取消关联、跨空间原件物理隔离；拖放成功/冲突/取消；同名原件的人工选择分支。
4. 已修复的 P0/P1/P2：三级目录、最新版本单行、批量删除去重、锁定拒绝不清会话、PDF 两页实际 Canvas 渲染、业务接口 500 明示失败、回收站混合清空及 201/403 条分批。
5. Excel 合法/错误/重复行导入导出、ZIP 导出进行中切工作区、33 MiB 和超过 2 GiB 的上传/取消/下载/版本往返、上传/导出/压缩/永久删除四类任务期间切工作区与关库、刷新恢复任务状态、权限及异常数据输入。
6. 不同分辨率/缩放的表格可用性；误操作与失效入口检查；Ctrl+A、Esc、Delete、F2、拖放与右键行为；完成后检查 SQLCipher 完整性、孤立对象与原件 SHA。

结果分为 **PASS / CONFIRMED_BUG / IMPLEMENTATION_GAP / BLOCKED / TEST_ERROR**；每条带复现步骤、最新 SHA、输入输出或截图。Agent 报错不直接作为产品缺陷，必须做独立审查与复现。禁止为了测试全绿弱化安全约束或覆盖真实用户数据。
