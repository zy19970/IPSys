## 拟交付回复

**IPSys 已经可以进入日常使用中的功能精修。** 它是一款 Windows 本地资料管理器，界面沿用 OneDrive 的操作方式。个人和公司资料、附件原件及版本集中保存在同一个 SQLCipher 加密库里，两个工作区的数据相互隔离。本机可以通过浏览器手动整理，也可以通过 MCP 让 Agent 搜索、归档和补全属性。

## 仓库现在的结构

| 范围 | 现行实现 |
| --- | --- |
| Windows 程序 | WinForms 负责启动、托盘和安全退出。ASP.NET Core 只监听本机地址，在 Edge 或 Chrome 打开 Explorer。自包含版可用一个 EXE 运行。 |
| 资料模型 | 公司与个人工作区各六个栏目。项目和知识产权有专用台账，项目下的合同材料用普通文件夹管理。附件有版本，目录支持嵌套、移动和回收恢复。 |
| 前端和 MCP | 正式前端在 `src/IPSys.Web/wwwroot`，构建时嵌入 EXE。MCP 由同一个 EXE 提供，接入后用 `tools/list` 获取实际可用工具，上传和检索按工作区、栏目及资源 ID 定位。 |
| 文档和验证 | `docs/CURRENT_BASELINE.md` 汇总现状，`UI_BASELINE.md` 约定交互。`docs/wiki/` 是用户帮助的发布源，`src/IPSys.Web/tests/` 和 `tests/` 提供自动回归入口。 |
