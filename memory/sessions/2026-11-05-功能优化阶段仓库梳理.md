### 技术建议与边界

建议第一阶段实现只读 Markdown 预览：点击/右键预览打开同一弹窗，支持标题、段落、强调、表格、清单、任务清单、代码块、引用与安全链接，提供“预览/源码”切换，并顺手支持 .txt 纯文本阅读。选择本地打包的 Markdown 解析器（如 Marked）搭配净化器（如 DOMPurify）：Marked 本身明确不净化 HTML，因此不允许未清洗 HTML 直接 innerHTML；外部图片及远程资源不自动拉取，危险协议与事件处理属性禁止执行；相对图片地址不能当作真实磁盘相对路径，应作为后续附件关联/权限能力单独设计。文本大小设置保守阈值和编码/取消/错误反馈，渲染后清理资源，维持现行 CSP、会话/工作区隔离与 FileId 版本读取。

“实时”的合理默认含义是打开时立即渲染**数据库中当前文件版本**；若用户想外部编辑器实时写盘然后 IPSys 无上传自动变化，那需要单独的本地文件监控/自动保存/版本冲突功能，目前架构没有同步机制，不应擅自增加。可以后续再考虑真正所见即所得编辑或实时双栏编辑，这不是本轮请求的必要范围。
