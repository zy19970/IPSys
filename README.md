# IPSys — 知识产权与综合资料管理系统

IPSys 是面向 **Windows 10/11 x64** 的离线便携式单用户资料管理系统，使用加密 SQLite 主数据库归档业务台账与原始附件，区分公司与个人工作区，通过本机 Edge/Chrome 浏览器使用。

> **当前阶段：V1.0 产品需求已冻结；技术方案尚待验证，应用尚未开发完成。**  
> **当前任务：U0 UI 已获用户确认冻结**，界面基线见 [UI_BASELINE.md](./UI_BASELINE.md)；M0 已完成，M1 仍有超大文件、SSD 故障、备份与选择目录等关键验证待办。先在现有 SQLCipher 综合资料中逐项开发和验证真实业务功能，其余模块仍为演示。完整技术设计和全面业务开发须遵循 M1/M2 门槛。**  
> 请勿把历史 DESIGN.md 中的探索功能当作现行产品需求。

## 最快开始测试 WinForms 启动器与网页

1. 打开 [IPSys Windows 构建工作流](https://github.com/zy19970/IPSys/actions/workflows/web-windows.yml)，选择最新成功运行，在 **Artifacts** 下载 `IPSys-Web-win-x64`。
2. 解压后双击 `IPSys.Web.exe`，点击 WinForms 唯一的“打开浏览器管理界面”按钮。**新版主界面 HTML/CSS/JS 全部编译进 EXE**，不需要外置 `wwwroot` 文件。
3. 默认显示**打开已有资料库**：输入数据库路径及密码解锁；首次使用时点击登录表单下方的「＋ 新建资料库」进入创建界面，可再点击「返回打开资料库」。解锁后**先选择公司/个人工作区**；在左侧「综合资料」中新建记录、修改资料名称、上传和下载非敏感文件；其他模块仍是示例，功能会逐项接入；通过顶部入口切换工作区，完成后安全退出。
4. 请阅读 [WEB_TESTING.md](./WEB_TESTING.md) 的细节和原型限制。本次是可以操作的**最小业务网页**，不是完整 IPSys V1.0。

## UI 冻结与真实功能开发

用户已确认当前界面可以冻结。**显示规则、导航、资料类别卡片 → 分类台账 → 单条详情、项目/知识产权/合同表格及单页详情**以 [UI_BASELINE.md](./UI_BASELINE.md) 为准。UI 目前冻结的是布局和交互结构，不是全部业务已上线；新增真实功能时复用现有控件，不额外修改外观。

真实功能从 SQLCipher 内已存在的「综合资料/其他资料」开始：创建、修改记录名称、附件上传下载。是否完成以最新 Windows CI 的 SQLCipher/HTTP 测试及本机复核为准。

## 登录默认入口与台账密度

初始未解锁页默认采用已有库登录状态，只显示数据库路径、密码及「解锁并进入」，新建资料库由下方独立按钮进入，不再与登录并列作为默认选项。业务台账正文提高至 15 px、列头 13 px，少量记录时表格高度按数据行自然收缩；附件列表与原有业务功能不受影响。

## 全系统界面已合并到主入口（UI V0.2）

现在双击 `IPSys.Web.exe` 后，WinForms **只保留一个「打开浏览器管理界面」按钮**，直接打开新版主界面：解锁或创建加密资料库 → 主动选择「公司资料」或「个人资料」 → 进入带左侧模块导航的工作台。新版布局包含知识产权、科研项目、横向项目、全部合同、证件、综合资料和系统设置；知识产权及项目详情在**一页中上下展开**。

**综合资料为真实 SQLCipher 数据和可用功能**：在新版台账中创建资料、进入独立详情并上传/下载原件，沿用现有 64 MiB 原型限制、安全退出和恢复会话；其他业务模块目前使用明显标为「界面示例／未接入业务」的模拟数据，不会误写入真实库。公司与个人的真实数据及演示内容分别显示。**个人工作区**另按个人履历资料归档方式设置「身份与资质 / 知识产权与著作 / 科研与合作项目 / 成果与奖励 / 学术与社会活动 / 其他资料」六个入口，合并重复的学历学位证书与同类奖励证明；其中「其他资料」继续接原有真实综合资料 API，前五类暂用明确标记的演示数据。公司工作区导航不变。**归档类别采用「类别卡片 → 分类台账 → 记录详情」三级浏览**：公司「企业资质」及个人「身份与资质、成果与奖励、学术与社会活动」先按类别展示卡片，点击「学术兼职」等类别卡片进入该类别的**多条记录表格**，然后点击某条记录才进入详情及附件。知识产权、科研及横向项目、合同继续保留原台账表格。公司「综合资料」与个人「其他资料」仍按现阶段真实资料记录显示卡片并进入详情、上传下载，不假设数据库已有分类字段。所有分类和多条记录样本都明确为演示，不属于真实 SQLCipher 数据。UI 布局先合并并供用户逐页调整，M1 技术验收和 M2 正式设计仍按计划进行。

原 [demo/ui-preview.html](./demo/ui-preview.html) 作为历史独立设计参考继续保留，`/ui-preview` 路由用于必要时对照；**日常使用无需打开预览入口**。本次导航采用用户在设计阶段最新反馈的「科研项目／横向项目」，并未改写冻结需求中的其它项目与科研成果范围，正式开发前需统一需求基线。详见 [WEB_TESTING.md](./WEB_TESTING.md)。
